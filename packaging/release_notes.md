## 下載

| 平台 | 檔案 |
|---|---|
| Windows | `*-windows-x64-setup.exe`（安裝程式）或 `*-windows-x64.zip`（免安裝） |
| macOS | `*-macos.dmg`（Apple Silicon 與 Intel） |
| Linux | `*-linux-x86_64.AppImage` 或 `*-linux-x86_64.tar.gz` |
| Android | `*-android-arm64-v8a.apk`（多數手機）；舊手機用 `armeabi-v7a` |

## 第一次開啟

- Windows：安裝檔沒有程式碼簽章，SmartScreen 出現警告時選「其他資訊 → 仍要執行」。HEIC 需從 Microsoft Store 安裝「HEIF 影像延伸模組」與「HEVC 視訊延伸模組」
- macOS：未經 Apple 公證，第一次請在 App 上按右鍵 →「打開」
- Linux：AppImage 需 `chmod +x` 後執行；HEIC 需安裝 `libheif1` 與 `libheif-plugin-libde265`
- Android：需允許「安裝不明應用程式」；HEIC 需 Android 11 以上
